# Prakhar Priyansh · UX Portfolio

Static portfolio site, ready for GitHub Pages.

| File | Page |
|---|---|
| `index.html` | Landing page |
| `response-tab.html` | Response Tab case study |
| `ient-mobile.html` | IENT Mobile case study |

All images are embedded, so there are no asset folders. Fonts load from Google Fonts and Fontshare.

## Publish

1. Create a repo (name it `<username>.github.io` to serve from the root domain).
2. Upload these files to the repo root.
3. Settings → Pages → Deploy from branch → `main` / `/ (root)`.
